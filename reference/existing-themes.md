# Themes that already exist (in the Ruvva app, not in this repo)

Every new theme must be compared against these **and** against every folder in `themes/`
(brief section 7). A new theme may share at most 3 of the 13 axes with each of them.

## Royal Maroon (`royal-maroon`) — basic, typographic

Concept: the arjun-priya look — maroon and antique gold on ivory, set in type.

| # | Axis | Choice |
|---|---|---|
| 1 | Palette | jewel-dark: maroon `#7B1F3E`, deep `#5A1530`, gold `#C5975B`, ivory `#FFF8F0`, cream `#FDF5E6` |
| 2 | Type | Cormorant Garamond + Plus Jakarta Sans + Great Vibes (ampersand) |
| 3 | Opening | fixed card that fades away ("envelope" in name only) |
| 4 | Shapes | straight blocks, thin L-corner brackets |
| 5 | Ornament | line mandala, diamond-on-rule dividers |
| 6 | Hero | centred names on a radial colour field |
| 7 | Couple | two circles, stacked on phone |
| 8 | Countdown | outlined boxes, 2×2 on phone, digit flip |
| 9 | Events | vertical timeline line on the left, line fills on scroll |
| 10 | Gallery | not built yet |
| 11 | Motion | slow and sacred |
| 12 | Texture | none (flat gradients) |
| 13 | Desktop | not built yet (phone column) |

## Rose Mandap (`rose-mandap`) — illustrated prototype

Concept: a lamp-lit mandapam archway at night, red velvet curtains, then a blush page.

| # | Axis | Choice |
|---|---|---|
| 1 | Palette | jewel-dark opening `#3A000A` + gold `#ECC98F`, page blush `#FAF5EE` + rose `#E32D68` |
| 2 | Type | Playfair Display + Cinzel + Great Vibes + Montserrat |
| 3 | Opening | zoom into an archway, red velvet curtains part |
| 4 | Shapes | rounded cards, watercolour flower corners |
| 5 | Ornament | watercolour roses and leaves (bitmap) |
| 6 | Hero | large photo on top, names below |
| 7 | Couple | families as two text cards (no photos) |
| 8 | Countdown | four boxes in a row over a lit floral arch |
| 9 | Events | stacked cards with icon on the left |
| 10 | Gallery | none (story beats with photos instead) |
| 11 | Motion | cinematic |
| 12 | Texture | watercolour |
| 13 | Desktop | phone column |

Never build another maroon-and-gold typographic theme, and never another velvet-curtain
opening.

# Storybook Garden assets

All final illustration assets were made with the built-in imagegen tool for this project. The user attachment is a style reference only and is not shipped. People are fictional adults; no celebrity images, stock images or third-party music are used. Early photographic-looking variants were discarded. Character story variants reference the final generated cartoon couple for consistency. All project assets are copied into this theme folder and optimized to WebP; generated PNG originals remain in the Codex generated_images directory. Production uses no remote media URLs.

## Other assets

Inline SVG wood board, butterflies, sprigs, bench, divider and icons: original authored code, no external licence. Shared silhouette sample WebPs: copied from shared/sample-assets, repository-owned placeholder illustrations; retained for alternate data samples. assets/sample/music.mp3: original 24-second plucked-bell waltz synthesized by qa/make-music.py, no external recordings. Fonts: Bree Serif and Plus Jakarta Sans via Google Fonts CSS, open font licences. No transparent bitmap is used, so there is no baked checkerboard or alpha extraction.

All text including names is HTML, never part of a generated image. The venue art is an illustrative sample, not a verified depiction of a real venue.

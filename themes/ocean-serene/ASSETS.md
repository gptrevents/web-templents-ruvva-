# Ocean Serene assets

Original local sample artwork made with the built-in imagegen tool for this project. The moodboard is a style reference only, not a shipped image. All people are fictional adults, not real guests or celebrities. The generated venue sample is not claimed to depict the named sample venue. No stock photography, external media requests or third-party music.

## Code and other sources

Original inline SVG supplies gulls with articulated wings, cloud banks, animated foam and shell dividers; CSS and SVG displacement supply water motion. No alpha bitmap is used. Shared placeholder WebPs were copied before implementation, and remain for alternate samples. Music is synthesized locally from an original score (qa/make-music.py). Fonts: Italiana and Outfit, open font licences via Google Fonts CSS. Raw generated PNGs remain in Codex generated_images; optimized WebPs live in this theme's assets/ folder. Names and captions are always live HTML.

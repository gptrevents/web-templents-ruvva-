# Floral Elegant assets

Generated with the built-in imagegen tool for this theme. No reference-site code, real-person photographs or Temple Dawn artwork is used. The couple consists of fictional adults. The user's attached moodboard guided composition and palette; its pixels are not included in the production files.

Local WebP derivatives: floral-phone.webp (600×900, quality 80); floral-desktop.webp (1440×960, quality 80); couple.webp; groom.webp and bride.webp portrait crops; garden.webp; blossoms.webp detail crop; walk.webp. Conversion/crops use cwebp. All are opaque photographs; decorative flowers/icons are original inline SVG, so no cutout-alpha ambiguity.

Fonts: Lora, Nunito Sans and Parisienne via Google Fonts, SIL Open Font Licence. Parisienne is reserved for ampersands and fixed English decoration; data names use Lora or the integration's Indic fallback. Original sample placeholders and generated drone were copied from shared/sample-assets first.

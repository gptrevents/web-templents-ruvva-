## Step 2 — Design review
Compared Royal Maroon and Rose Mandap plus every current theme folder. This board explicitly requests a green botanical housewarming page, allowing broad photographic/garden overlap. It has no sacred tableaux, ritual vine, gold family medallions or decorated doorway clock from Griha Mangalam. The collage, photo-backed itinerary and terrace night scene are the organizing structures. Distinctness review complete before asset generation; full table follows in delivery review.

## Data and judgement calls
The default is a fictional home and host family, with no household portraits because the supplied modern reference uses interiors instead. Canonical wedding data still render side-matched portraits/monograms. Four events include optional description and photo fields; date, full venue/address and Maps actions are accessible in each row disclosure. Landmarks are labels only: no estimated travel times invented. The dining-room photo represents the lunch setting rather than an illustrated food platter.

Default gallery/video/live/gifts are hidden because the sample has no supplied media or enabled gifts. Fixture tests exercise these features. No real RSVP or payment was sent. Actual RSVP storage requires the documented host callback; Google Maps rendering depends on its embed service and network. Source photos are original generated fictional architecture, not a real family's property. Night blue is an intentional closing scene in the same evergreen/amber lighting direction, per the supplied board.

# Temple Dawn photographic assets — second edition

Created with the built-in imagegen tool on 18 October 2026 for this project. All depicted people are fictional generated adults. These are generated editorial assets, not photographs of an actual wedding. No celebrity references or reference-site media were used. Original PNG outputs remain in the Codex generated_images folder; production WebPs are local in `assets/`.

Images are opaque photographs, not transparent cutouts. `cwebp` performs format conversion, responsive resizing and portrait/detail crops. Backgrounds use quality 80. No text is baked into these assets. Google Fonts: Cormorant Garamond and DM Sans, SIL Open Font License. The repository's original generated drone is unchanged.

## Original SVG refinement
All SVG is drawn directly in app.js: brass pedestal lamp with inner/outer flame, crown-and-clapper bell, ten ceremony icons, lotus-and-leaf dividers, veined botanical sprigs with small jasmine blossoms, curved falling petals, music/pause/share controls. Every illustration uses currentColor, rounded strokes and restrained translucent fills; ornament and icon SVG is aria-hidden and nonfocusable. CSS supplies gentle flame and petal motion with a global reduced-motion override. No new raster assets were needed for this refinement.
